# Low-Cost RAG System (LangChain + FAISS + Redis)

This project implements a production-style Retrieval-Augmented Generation (RAG) system
using LangChain, FAISS, Redis, and multiple chunking and reranking strategies.

## Goals
- Compare chunking strategies and similarity metrics
- Implement FAISS-based retrieval
- Add reranking for higher precision
- Use Redis for caching and session memory
- Keep AWS cost minimal

## Tech Stack
- Python
- LangChain
- FAISS
- Redis
- OpenAI embeddings (initially)

## Why This Project
This project is designed to demonstrate  RAG systems,
including tradeoffs in chunking, retrieval, reranking, and cost optimization.
